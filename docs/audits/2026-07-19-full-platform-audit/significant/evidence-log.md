## Browser-confirmed Significant findings

### SIG-BP1-01: Confetti survives navigation and overlays later wrong states

After a correct level 1 result, rapidly continuing to level 2 and making an incorrect call left the original canvas active. The screenshot shows celebratory particles across the wrong-result icon, headline, comparison, and explanation. The wrong branch does not call the confetti function, so the defect is lifecycle leakage from the prior success rather than incorrect branching.

### SIG-BP1-02: Refresh can erase a miss and preserve first-try credit

The campaign records the decision only when the player presses the result CTA. Refreshing the wrong reveal restores the deciding card with an empty campaign record. Answering correctly afterward produced `attempts:1` and three stars. The same boundary can be used to reroll the random critical-insight bonus before committing the result.

### SIG-BP1-03: The fixed canvas makes 200 percent zoom non-completable

At 195 x 422 CSS pixels, the experiment card enlarges correctly but the document remains locked to 195 x 422 with no scroll range. All three decision buttons are positioned below y 809.5, so keyboard, pointer, and touch users cannot reach the required action.

### SIG-BP2-01: Wrong calibration and correct calibration both add 50 XP

The incorrect card is now visually corrective and uses the intended review icon, but the header immediately changes from 0 XP to 50 XP for Ship, Kill, and Keep Running. Calling it practice XP helps, but the identical reward still softens the distinction the result redesign is meant to create.

### SIG-BP2-02: Clipboard denial has no usable fallback

When clipboard permission is denied, the interface announces the error but leaves only the same failing button. The selectable textarea fallback is rendered only when the Clipboard API is completely unavailable.

### SIG-BP2-03: Calibration says 1 of 3 but completes after one decision

The progress language and three-dot model imply three calibration rounds. The first choice immediately produces Calibration complete and exits to the campaign. A reviewer can interpret this as an unfinished onboarding sequence.

## Strengths to preserve

- The entry world is distinctive, full-bleed on mobile, and intentionally locked to a mobile canvas on desktop.
- The evidence cards expose real numbers and readable decision data without requiring hidden gestures.
- Correct and isolated incorrect outcomes now use different assets, color systems, copy structures, audio paths, and reward treatment.
- Campaign gating, daily eligibility, baseline XP, replay XP, and share-success feedback persist correctly.
- Keyboard activation, focus visibility, locked-level semantics, polite result announcements, and reduced-motion persistence are present even though focus restoration and zoom still need work.
- The ten-case run is substantial enough to demonstrate a real curriculum and not only a visual prototype.
